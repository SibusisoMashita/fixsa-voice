# Short description

FixSA Voice is a mobile-first AssemblyAI voice agent that turns a resident’s natural spoken report about a water leak, pothole, electricity fault, sewer overflow, broken streetlight, illegal dumping, or damaged public asset into a complete, deduplicated, trackable work order. It asks only for missing detail, explains likely duplicates, reads the report back, and requires explicit confirmation before creating or merging a synthetic demo request. Immediate-danger speech stops ordinary automation and shows emergency guidance.
