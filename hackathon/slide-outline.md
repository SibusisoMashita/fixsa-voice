   Speak → clarify → deduplicate → read back → confirm → create/merge → track.

   Real-time partials, end-of-turn handling, interruption-aware replies, spoken output, and JSON-schema tool calls.

   Show all eight tools and the progressive confirmation gate.

   Consent, ephemeral audio, redacted public fields, immediate-danger stop, no fabricated emergency number.

8. **Resident and operations value**
   Accessible intake, self-service tracking, complete records, SLA visibility, fewer repeat dispatches.

9. **Architecture built for a reliable demo and real integration**
   Deterministic adapter, real Voice Agent adapter, shared contracts, server-only tokens, Postgres-ready schema.
